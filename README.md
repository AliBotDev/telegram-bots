# Nexa AI

Nexa AI is a Telegram AI assistant powered by Google Gemini.

## Features

- AI-powered conversations
- Conversation memory
- Automatic language detection
- Multiple Gemini model fallbacks
- `/start` command
- `/help` command
- `/clear` command
- `/status` command
- Error handling and retries
- Long message support

## Requirements

- Python 3.8+
- Telegram Bot Token
- Google Gemini API Key

# 🤖 Telegram Bots & Automation

A collection of **Telegram bots, automation tools, and utility projects** built with Python.

Each project in this repository is developed independently and focuses on a different practical use case.

## 📂 Projects

### 🧠 FlashCards

A Telegram bot for learning vocabulary with **flashcards and spaced repetition**.

**Features:**

* Multilingual vocabulary
* Automatic study decks
* Level-based learning
* Spaced repetition
* Learning statistics
* Custom flashcards

**Technology:**

* Python
* aiogram
* SQLite

➡️ [Open FlashCards](./FlashCards)

---

### 🤖 Nexa AI

An **AI-powered Telegram bot** designed for intelligent interactions and automation.

**Features:**

* AI-powered conversations
* Telegram bot interface
* Automated responses
* Extensible architecture
* API-based integrations

**Technology:**

* Python
* Telegram Bot API
* AI / LLM APIs

➡️ [Open Nexa AI](./Nexa%20AI)

---

### 📁 Universal File Converter

A Telegram-based utility for **converting files between different formats**.

**Features:**

* File uploads through Telegram
* Automatic file processing
* Multiple conversion formats
* Simple Telegram interface
* Automated conversion workflow

**Technology:**

* Python
* Telegram Bot API
* File-processing libraries

➡️ [Open Universal-File-Converter](./Universal-File-Converter)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/AliBotDev/telegram-bots.git
cd telegram-bots
```

Choose the project you want to use:

```bash
cd FlashCards
```

or:

```bash
cd "Nexa AI"
```

or:

```bash
cd Universal-File-Converter
```

Each project contains its own README with installation, configuration, and usage instructions.

## 🔐 Security

Do not commit sensitive information to the repository.

Examples:

```text
.env
API keys
Telegram bot tokens
Passwords
Private databases
User data
```

Recommended `.gitignore`:

```gitignore
.env
*.db
__pycache__/
*.pyc
venv/
.venv/
.idea/
.vscode/
```
